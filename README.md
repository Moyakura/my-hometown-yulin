# 魅力玉林 · 我的家乡——广西玉林文旅主题网站

> 一城岭南美玉，千年古州风华。山环水抱之间，藏着最抚凡人心的烟火味道。

**在线预览：** https://moyakura.github.io/my-hometown-yulin/

**源码仓库：** https://github.com/Moyakura/my-hometown-yulin

## 一、项目简介

本网站是《人工智能导论》课程实践作品，以**我的家乡——广西玉林**为主题，通过图文与影像展现玉林的山水自然、人文古迹、特色美食与民俗非遗。

设计上采用**青绿（#2f6f4f）+ 米白（#f7f3e8）**主色，融合国风水墨意境与现代简约排版；内容组织遵循「**图片为主、文字精炼**」的原则，让风景本身说话。

站点采用**多页面结构**：内容按主题拆分为独立页面，彼此通过导航、面包屑与上下页翻页互相跳转，避免所有素材堆在一个文件里导致加载缓慢。

| 页面 | 内容 |
|------|------|
| **`index.html`** | 门户首页：Hero 首屏、站点前言、概览数据、**四大板块入口卡片**、影像速览（仅封面图） |

**跳转方式**：顶栏全局导航（当前页高亮）· 面包屑返回 · 章节卡片入口 · 页脚导航 · 每页底部的上一篇/下一篇。

## 三、页面结构（内容页通用）

1. **章节 Banner**：主题大图 + 章节标题 + 导语（比首页 Hero 更轻）
2. **面包屑**：首页 / 当前章节
3. **图文交错条目**：每个主题点为一整行，图文左右交替；正文含名称、简介、要点清单、标签、来源直链
4. **相册缩略图**：每处 2–4 张图，点击开灯箱
5. **本章影像**：该章节所属视频，卡片式封面 + 点击播放
6. **上下页导航 + 页脚**

## 四、交互特性

- **平滑滚动**：`scroll-padding-top` 让锚点定位自动避开固定顶栏（此前会被遮挡）
- **卡片悬浮上浮**：hover 上浮 10px、图片缓放大
- **图片灯箱**：点击主图或缩略图打开，支持左右翻页 / 键盘 ←→ / Esc / 移动端滑动 / 背景点击关闭
- **滚动渐现**：区块进入视口时错峰淡入
- **返回顶部**：超过一屏后出现右下角悬浮按钮
- **视频互斥播放**：播放新视频自动暂停其他视频
- **视频全屏**：优先原生 Fullscreen API；若在内嵌 iframe（如编辑器预览）中被拒绝，自动降级为「影院模式」全屏覆盖层
- **移动端适配**：900px 以下导航折叠为汉堡菜单，单列布局
- **无障碍**：`prefers-reduced-motion` 下自动关闭动画

## 五、加载性能

| 优化项 | 说明 |
|--------|------|
| **双档图片变体** | 内联展示用 1280px 版（均约 150KB），相册缩略图用 440px 版（均约 **23KB**，原直接加载 280KB 大图）；原图仅供电箱查看 |
| **视频重编码** | 15 段统一限制到 1280×960 以内、码率 480kbps + `+faststart`，**357MB → 124MB（-65%）**，边下边播无需等完整个文件 |
| **PNG 转 JPG** | 客家山歌、桂南采茶戏等舞台照由 MB 级 PNG 转为 JPG |
| **视频首帧封面** | 用 ffmpeg 为 15 段视频各生成一张独立封面（26–105KB），列表页不再加载视频本身 |
| **视频懒加载** | 视频用 `data-src` 承载真实地址，进入视口前 200px 才写入 `src`，配合 `preload="none"` |
| **图片懒加载** | 非首屏图片全部 `loading="lazy"` + `decoding="async"` |
| **宽高属性** | 每张 `img` 都写了 `width`/`height`，浏览器可预留空间，消除布局抖动（CLS） |
| **首图预加载** | 首页 Hero 使用 `<link rel="preload" as="image">` 提前拉取 |
| **公共静态资源** | CSS / JS 抽到 `assets/`，多页共用一次缓存，翻页无需重复下载 |
| **首帧体积** | 单页 HTML 仅 10–20KB，首页首屏只加载 1 张大图 |

**实测每页图片负载**（懒加载范围内全部图片之和）：

| 页面 | 优化前 | 优化后 |
|------|--------|--------|
| 首页 | 931KB | 943KB（均为卡片大图） |
| 山水自然 | 3717KB | **920KB（-75%）** |
| 人文古迹 | 2806KB | **853KB（-70%）** |
| 特色美食 | 3399KB | **1087KB（-68%）** |
| 民俗非遗 | 2540KB | **843KB（-67%）** |
| 关于玉林 | 193KB | 143KB |

## 六、技术实现

- **多页面 + 公共资产**：`index/nature/culture/food/folk/about` 六个 HTML，共用一份 CSS 与一份 JS
- **原生技术栈**：语义化 HTML5 + CSS Grid/Flex + 原生 ES5 JavaScript，无框架、无构建、无 CDN
- **相对路径引用**：图片 `images/子文件夹名/...`，视频 `videos/子文件夹名/...`
- **注释清晰**：CSS 分 18 个编号模块，JS 分 7 个功能模块，均为中文注释
- **中文排版**：统一 `line-height:1.9`、`letter-spacing`；标题使用 `text-wrap:pretty` 避免末行孤字

## 九、本地运行

**方式一：直接打开**
双击 `index.html` 即可在浏览器中查看。

**方式二：本地服务器**（推荐，懒加载与视频播放体验更完整）
```bash
cd 工作区
python -m http.server 8000
# 浏览器访问 http://127.0.0.1:8000
```

> 说明：素材文件名为中文且含 `#`、空格、emoji 等特殊字符，已在 HTML 中按 URL 规则转义（`#` → `%23`，空格 → `%20`）。**请勿直接重命名素材文件**，否则需同步更新对应页面中的引用路径。
