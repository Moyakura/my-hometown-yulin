# 魅力玉林 · 我的家乡——广西玉林文旅主题网站

> 一城岭南美玉，千年古州风华。山环水抱之间，藏着最抚凡人心的烟火味道。

**在线预览：** https://moyakura.github.io/my-hometown-yulin/

**源码仓库：** https://github.com/Moyakura/my-hometown-yulin

## 一、项目简介

本网站是《人工智能导论》课程实践作品，以**我的家乡——广西玉林**为主题，通过图文与影像展现玉林的山水自然、人文古迹、特色美食与民俗非遗。

设计上采用**青绿（#2f6f4f）+ 米白（#f7f3e8）**主色，融国风水墨意境于现代简约排版；内容组织遵循"**图片为主、文字精炼**"的原则，让风景本身说话。

## 三、交互特性

- **导航平滑滚动**：点击导航自动减去顶栏高度精准定位，并同步高亮当前区块
- **卡片悬浮上浮**：hover 时卡片上浮 10px、图片缓放大至 1.08 倍
- **图片灯箱**：点击图片弹出大图，支持左右翻页 / 键盘 ←→ / Esc / 移动端滑动 / 背景点击关闭
- **滚动渐现**：区块进入视口时错峰淡入上移
- **返回顶部**：滚动超过一屏后右下角出现悬浮按钮
- **视频互斥播放**：播放新视频自动暂停其他视频；支持**原生全屏**，被 iframe 限制时自动降级为「影院模式」
- **移动端适配**：900px 以下导航折叠为汉堡菜单，布局单列化
- **无障碍**：`prefers-reduced-motion` 下自动关闭动画

## 四、技术实现

- **单文件自包含**：`index.html` 内联全部 CSS 与 JS，零外部框架、零 CDN 依赖
- **相对路径引用**：图片 `images/子文件夹名/...`，视频 `videos/子文件夹名/...`
- **原生技术栈**：语义化 HTML5 + CSS Grid/Flex + 原生 ES5 JavaScript（无构建、无编译）
- **性能优化**：视频 `preload="none"` + 卡片图作封面；图片 `loading="lazy"`
- **注释清晰**：CSS 分 13 个编号模块，JS 分 8 个功能模块，均带中文注释

## 六、素材来源与数据出处

- **图片 / 视频素材**：各采集自抖音公开短视频，版权归原作者所有。每张卡片、每个视频卡片下方均标注了对应的来源直链；完整溯源清单见 [`资料/图像溯源.docx`](资料/图像溯源.docx)。
- **城市数据**：
  - 建置历史 2100+ 年：西汉元鼎六年（公元前 111 年）置郁林郡
  - 常住人口 580.42 万（2024 年末），户籍人口约 742 万
  - 国家 A 级旅游景区 44 家（含 4A 级 16 家，截至 2024 年 7 月）
  - 海外华侨及港澳台同胞 220 万+
  - 参考：玉林市人民政府门户网站《玉林市概况》《玉林旅游导图》

## 七、本地运行

**方式一：直接打开**
双击 `index.html` 即可在浏览器中查看。

**方式二：本地服务器**（推荐，视频播放与全屏体验更完整）
```bash
cd 工作区
python -m http.server 8000
# 浏览器访问 http://127.0.0.1:8000
```

> 说明：素材文件名为中文且含 `#`、空格等特殊字符，已在 HTML 中按 URL 规则转义（如 `#` → `%23`）。请勿直接重命名素材文件，否则需同步更新 `index.html` 中的引用路径。
